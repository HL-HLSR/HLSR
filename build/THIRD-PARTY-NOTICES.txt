Bunnymod XT
===============================================================================

Project:
https://github.com/YaLTeR/BunnymodXT

Bunnymod XT is a speedrunning and TAS tool for Half-Life and related games.
Some speedrunning commands or functionality in Ghosting Mod were inspired by
or adapted from Bunnymod XT.

In the HLSR Launcher this applies to the console script editor: the
bxt_* command inventory and its argument syntax in
src/renderer/utils/hlscripts.js are adapted from the Bunnymod XT
command set.

It also applies to the shape of the Discord Rich Presence card: showing the
current map as the large image and the run state as a small circular overlay
follows Bunnymod XT's discord_integration. The HLSR implementation
(src/main/discord-rpc, src/main/game-presence) is written from scratch for
this architecture; no Bunnymod XT code is copied.

The full original LICENSE file of Bunnymod XT follows verbatim. It also
carries the notices of components bundled inside that project; none of them
have been removed or shortened.
