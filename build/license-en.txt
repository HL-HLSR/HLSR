4. MINIMAL TECHNICAL TELEMETRY

By accepting this agreement you allow HLSR to send the minimal technical
statistics needed to assess stability and fix errors. Sending is on by
default. You can switch it off with the "Technical statistics" toggle in
HLSR settings.

That can include:

  - the HLSR version and the installed build version;
  - the Windows version and architecture;
  - the type of operation performed: install, update, launch or error;
  - a general result or error code;
  - the time of the event, without the contents of user files.

As with any network connection, the server and the hosting provider
handle the IP address briefly: that is an ordinary technical part of an
HTTP request.

When technical telemetry is enabled in Settings, HLSR may send only the
launcher technical events listed above. The data goes over HTTPS to
api.hlsr.pro and nowhere else.

That is about telemetry. The launcher reaches the network in three more
cases, and none of these requests carries any statistics:

  - for launcher and build updates, it goes to hlsr.pro, or to the backup
    mirror on github.com when hlsr.pro is unreachable;
  - for the avatars of the Steam friends missing from the local Steam
    cache, it goes to steamcommunity.com. Only the Steam profile number
    leaves your computer, and it goes to Valve, not to us. The downloaded
    picture is kept on your computer, and the launcher does not ask for it
    a second time;
  - for the «playing now» counter, it goes to api.hlsr.pro once a minute
    while the launcher window is open. The request has no body: the
    launcher asks for a number and tells nothing about you. It also runs
    with telemetry disabled, which is why it is named separately here:
    telemetry being off means HLSR collects and sends nothing about you,
    not that no network requests remain at all.

Telemetry can be turned off at any time in the HLSR settings. After it
is disabled, new events are not created, the local queue is deleted, and
sending stops. Turning telemetry off does not prevent installing,
updating or launching a game.

HLSR can show in Discord that you are playing: the build name, the map
name, the frame rate and the time spent in the app. This is Rich
Presence, the same «Playing...» line any game shows in Steam or Discord.
It appears inside Discord and is visible to people already on your
friends list; none of it reaches our servers. The feature is on by
default and is turned off by a single switch in the HLSR settings.

A diagnostic archive, a crash report, technical logs and user files are
created or stored only by your explicit action. HLSR never uploads them
automatically.

8. UNINSTALLATION

When HLSR is uninstalled, the game builds it installed are removed
together with the program. Saved games, configs, demos and screenshots
stored inside those builds are lost. Back them up beforehand if you need
them. The exact folder to be deleted is shown in the uninstall window
before you confirm.

Updating HLSR does not delete games: they are removed only when the
program itself is uninstalled.

In addition, when uninstalling you can choose whether to:

  - keep or delete your local profile statistics;
  - keep or delete your settings and logs.

By default, profile statistics, settings and logs are kept.
