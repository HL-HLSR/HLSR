# HLSR — интерфейс в стиле Windows 10 (WinUI 3)

Новое окно лаунчера HLSR. Логика остаётся в Rust-крейтах этого репозитория (доставка, платформа,
онлайн, обновление), интерфейс написан на C#/XAML (WinUI 3) и оформлен под Windows 10:
квадратные углы, Segoe UI и Segoe MDL2 Assets, рамки контролов в 2 px, акриловая панель
навигации с полоской акцента, заголовки Segoe UI Light.

## Как устроено

```
HLSR.WinUI (C#, WinUI 3)  ──P/Invoke──►  hlsr_ffi.dll (Rust, crates/hlsr-ffi)
   страницы, тема Win10                     DeliveryApi, PlatformApi, OnlineApi, UpdateApi
   Core/Backend.cs                          ChannelRouter — те же каналы, что у окна GPUI
```

- `crates/hlsr-ffi` повторяет запуск `hlsr-app` (`startup.rs`) без GPUI: всё, что службы
  просили у окна (показать, свернуть на время игры, выйти, HWND для диалогов), уходит хосту
  командами `host:<имя>`.
- C API: `hlsr_start`, `hlsr_invoke` (ответ приходит событием `reply`), `hlsr_send`,
  `hlsr_send_sync`, `hlsr_store_read/write`, `hlsr_window_state`, `hlsr_shutdown`.
- Каналы те же, что у `ipcRenderer` 0.4.x и окна GPUI: `game-delivery-get-status`,
  `game-process-launch`, `game-delivery-install`, `set-library-path`, `updater-check`…
- Строки берутся из `crates/hlsr-ui/locales/{ru,en}.json`, арт игр из `crates/hlsr-ui/assets`.

## Сборка

Нужны Rust из `rust-toolchain.toml`, .NET SDK 8 (закреплён в `global.json`) и Visual Studio
с C++ (для линковки Rust).

```powershell
cd winui
dotnet build -c Release
```

Сборка сама вызывает `cargo build -p hlsr-ffi` и кладёт рядом с `HLSR.exe` библиотеку
`hlsr_ffi.dll` и папку `resources` (7-Zip, оверлей LiveSplit, presence relay).
`-p:SkipRust=true` пропускает cargo, если DLL уже собрана.

Отладочная сборка понимает `HLSR_DATA_DIR` и `HLSR_LOGS_DIR`: так можно запускать окно
на отдельной папке данных и не трогать установленный HLSR.

## Что уже есть

- Окно с заголовком и навигацией как в «Параметрах» Windows 10; светлая и тёмная тема по ОС.
- Страницы игр (Ghosting, Half-Life 2 с выбором сборки 4260/2707/5288, Half-Life): арт,
  главная кнопка по `mainButton` (играть, установить, обновить, пауза, продолжить, закрыть
  игру, восстановить, «почему недоступно»), прогресс загрузки со скоростью и временем,
  отмена, меню управления игрой (папка, скриншоты, ярлык, обновления, проверка файлов,
  восстановление, удаление).
- Настройки: язык, папка библиотеки, лимит скорости, Discord Rich Presence, трей во время
  игры, диагностика с экспортом ZIP, обновление лаунчера, папка логов.
- Настройки игры (вкладки Pivot): параметры запуска, персонализация (HUD, прицел, панели BXT,
  паки HUD и прицелов, оверлей LiveSplit), редактор cfg, бинды по каталогу заготовок, демо игры
  (упаковка в ZIP), призраки и версия Ghosting.
- Эпизоды Ghosting, экспорт и импорт сборки (`.hlsrpack`), экспорт настроек и cfg.
- Главная (уведомления, объявления, рекорды), Инструменты (LiveSplit), Демо (FFmpeg, bxt-rs,
  экспорт демок в видео, сохранённые видео), Профиль (вход через Steam, статистика,
  достижения, друзья).
- Значок в трее на время игры (Shell_NotifyIcon): щелчок возвращает окно, меню — «Показать
  HLSR / Выход».
- Иконки — Segoe MDL2 Assets (Windows 10), а не Segoe Fluent Icons.

Каналы, которых не было у окна GPUI (оно брало данные из крейтов напрямую), — в
`crates/hlsr-ffi/src/winui.rs`: `winui-bind-presets` (каталог заготовок биндов).

## Чего пока нет (было в окне GPUI)

Визуальная клавиатура и предпросмотр прицела, встроенный видеоплеер «Демо» с отметкой клипа
(видео открывается в системном плеере), скрипты гайда HL1, кастомные паки моделей и звуков,
редактор сплитов LiveSplit, онлайн-статусы и поиск игроков, реакции на объявления, анимации
и темы оформления окна GPUI.

Установка игр в сборке из исходников недоступна: канал доставки включается только в
официальном лаунчере (`GAME_DELIVERY_REMOTE_ENABLED`), см. README в корне репозитория.
